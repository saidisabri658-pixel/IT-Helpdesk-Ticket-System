# IT Helpdesk Ticket System - C++

Ein konsolenbasiertes IT-Helpdesk-Ticketsystem, das mit C++ entwickelt wurde.

## Funktionen

- Neue Support-Tickets erstellen
- Alle Tickets anzeigen
- Tickets anhand der ID suchen
- Ticket-Status ändern
- Tickets löschen
- Prioritäten festlegen: Niedrig, Mittel oder Hoch
- Ticketdaten automatisch in einer Textdatei speichern
- Gespeicherte Tickets beim Programmstart laden

## Technologien

- C++
- Standard Template Library (STL)
- Dateioperationen
- Vektoren und Strukturen
- Visual Studio Code
- GCC / MinGW-w64

## Kompilieren

```bash
g++ main.cpp -o helpdesk.exe
```

## Ausführen

Unter Windows PowerShell:

```powershell
.\helpdesk.exe
```

## Ziel des Projekts

Dieses Projekt simuliert ein einfaches IT-Helpdesk-System und dient dazu, C++-Kenntnisse in den Bereichen Datenstrukturen, Funktionen, Dateioperationen und Datenverwaltung praktisch anzuwenden.
